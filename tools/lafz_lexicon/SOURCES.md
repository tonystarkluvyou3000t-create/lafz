# Source review and redistribution notes

Reviewed 2026-10-12 using the source publishers' download and license pages. This is engineering provenance documentation, not a legal opinion. The source registry is the machine-readable record used by the build.

## Selected sources

| Source | Selection and format | License and handling |
|---|---|---|
| [Open English WordNet](https://en-word.net/downloads) | Latest stable listed release: OEWN 2025, dated 2025-12-31. Available formats include WNDB ZIP (9.2 MB), compressed WN-LMF XML (10.8 MB), RDF/Turtle (16.9 MB), and JSON ZIP (9.5 MB); this pipeline uses WN-LMF XML. The 2025 base edition contains common lexical items; the separate `plus` archive adds curated names. Prefer the common-word release for the vocabulary app. | CC BY 4.0; preserve attribution. OEWN says it derives from Princeton WordNet. The website reports 120,068 synsets and 153,261 entries. The old Princeton 3.0 source remains a comparison-only reference. |
| [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict) | Current maintained GitHub dictionary text, approximately 3.45 MB at review. It has pronunciation variants in its word notation. The project does not publish a conventional immutable release for the current branch; the builder records the exact downloaded SHA-256. | CMU's README says research and commercial use are unrestricted and requests acknowledgement. Preserve the source notice. Output is North American ARPABET with stress digits, not IPA. |
| [New General Service List](https://www.newgeneralservicelist.com/new-general-service-list) | NGSL 1.2, 2,809 words, released April 2023 and still identified as latest by the project page. The official `NGSL_12_stats.csv` is selected because the official page says frequency data is in the basic-statistics file. | CC BY-SA 4.0. Keep frequency rank and derived tiers source-attributed. NGSL frequency rank is not a CEFR label. |
| [Kaikki.org raw Wiktextract dump](https://kaikki.org/dictionary/rawdata.html) | The page reports the enwiktionary dump date 2026-09-02 and extraction on 2026-10-03. Raw JSONL is multi-language and about 2.8 GB compressed. The parser streams it and retains only English (`lang_code == en`) entries that match existing OEWN headwords and accepted POS. The much larger English-only postprocessed JSONL (3.1 GB) is marked deprecated and its page says it may merge other sources; this build excludes it. | Kaikki says the raw data is available under the same licenses as Wiktionary, CC BY-SA and GFDL. Optional; keep its content separately attributable and review share-alike distribution before packaging. Wiktionary contributors and Wiktextract/Kaikki publication are credited. |
| [Simple English Wiktionary via Kaikki](https://kaikki.org/dictionary/rawdata.html) | Separate `simple-extract.jsonl.gz` is listed at about 4.5 MB compressed. It is imported only for matching OEWN headwords; learner-friendly glosses stay separate alternatives. | Simple English Wiktionary's copyright page references GFDL, and its footer identifies CC BY-SA. Retain source attribution and confirm the applicable Wikimedia license version for the retrieved snapshot before redistributing. |
| [Tatoeba downloads](https://tatoeba.org/en/downloads) | Local `eng_sentences.tsv.bz2` has the general export shape: sentence ID, `eng`, and text. It contains 2,038,719 rows, is bzip2-compressed, and has no per-row license column. It is therefore treated as the general English export, not the CC0 subset. The importer retains IDs, checks word/inflection presence, filters low-quality and near-duplicate candidates, and keeps at most three examples per word. | Tatoeba's general textual sentence downloads are CC BY 2.0 France; its guidance says to identify Tatoeba and link to the site. The CC0 subset is distinct and is not claimed for this archive. Imported sentences are stored as word-level examples with sense fit explicitly unverified; word presence does not establish sense fit. No audio is used. |
| Lafz lexical complexity heuristic | Generated 1–5 estimates use CMUdict syllable counts when available, otherwise an orthographic syllable estimate, plus word length, affix, and OEWN/Wiktionary specialist or usage signals. Per-row evidence and low confidence are stored. | Lafz-generated labels are not CEFR and are not presented as official proficiency data. Output remains source-attributed where it uses source-derived signals. |

## Evaluated but excluded

### wordfreq

The upstream package snapshot is approximately through 2021. Its code is Apache-2.0, while its data files are CC BY-SA 4.0 and carry several corpus-specific attribution notes. The project's README explicitly says not to convert its data into CSV because that loses attribution/license details, and explains that frequencies depend on its normalization and segmentation code. It is excluded from this SQLite distribution. NGSL is the selected transparent, learner-focused usefulness signal.

## Source registry fields

`source_registry.json` records publisher, upstream URL, version/date, format, license, attribution, redistribution conditions, role, and checksum field. Downloaded files are recorded in `cache/sources/source_manifest.json`. Offline builds also inventory every file under `source_archives/` and write its exact relative path, size, detected compression, SHA-256, source mapping, and inclusion decision to `build/full/reports/source_manifest.json`. File hashes identify the exact local CMUdict and Tatoeba snapshots when their upstream export date is not encoded.

## Compatibility and packaging decision

The source set combines CC BY OEWN, CMUdict's attribution-requested unrestricted data, NGSL CC BY-SA, Simple English Wiktionary share-alike content, and general Tatoeba sentences under CC BY 2.0 France. The NGSL XLSX workbook is inventoried but excluded when the official ranked CSV is present because it supplies only word-level definitions without POS or sense alignment. The all-language Kaikki archive was not supplied and remains optional. Imported content rows carry their `source_id`; `source_attributions` retains external identifiers that cannot be reconstructed from the content rows, notably Tatoeba sentence IDs. Full and Core both preserve the applicable per-source attribution/license metadata. Neither edition claims one umbrella license. Before public release of a database with any ShareAlike source, decide and document terms for the aggregate database and verify all included conditions.
